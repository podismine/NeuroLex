Overview

A vocabulary for human brain dynamics

The brain continuously moves through recurring large-scale configurations. NeuroLex represents these dynamics as a compact token sequence, creating a common language for quantifying how dynamic organization changes across age and differs across individuals.

01

Tokenize

Map continuous functional dynamics onto a reproducible vocabulary of recurrent brain states.

02

Characterize

Measure how frequently states occur, how long they persist, and how the system transitions over time.

03

Normalize

Model age-resolved population trajectories and translate them into individualized normative scores.

Framework

From signals to individualized reference maps

NeuroLex couples dynamic-state representation with normative modeling. The same compact representation supports population-level lifespan mapping and subject-level deviation analysis.

Key results

One reference, multiple scales of interpretation

The project page is structured around the scientific story rather than the paper figure order: lifespan organization first, individualized deviations second, and disorder-related alterations third.

Lifespan

Dynamic states follow distinct age-related trajectories

Different components of temporal brain organization exhibit characteristic changes from childhood through older adulthood.

Individuals

Population references become subject-level deviation profiles

Normative scores quantify where an individual lies relative to the expected lifespan distribution.

Brain disorders

Clinical groups show structured deviations from normative dynamics

The normative reference offers a common coordinate system for comparing altered brain dynamics across disorders.

Use NeuroLex

Run the pretrained pipeline on your data

The repository includes a pretrained NeuroLex checkpoint, example data, GAMLSS models, and scripts for token inference, temporal feature extraction, normative scoring, model fitting, and site transfer.

Quick start 
# environment
conda env create -f environment.yml
conda activate NeuroLex

# infer brain-state tokens
python 01-infer_tokens.py \
  --input_data demo_data/anonymous \
  --output_path results/token_results/train

# derive temporal features
python 02-gather_features.py \
  --token_folder results/token_results \
  --save_file results/temporal_features.csv

# compute normative z-scores
python 04-infer_zscore.py \
  --input_file results/temporal_features.csv \
  --load_model model/gamlss_model
